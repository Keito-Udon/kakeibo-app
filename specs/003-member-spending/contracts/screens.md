# Screen Contract: メンバー別の使用額の可視化

`specs/002-calendar-monthly-budget/contracts/screens.md` の「カレンダー」画面への差分。他の画面は変更しない。

## カレンダー（`/months/{YYYY-MM}`）

**役割**: 「表示中の月の支出状況を見る」（002では「その月の支出を日付ごとに見る」）。日付ごとの支出と
メンバーごとの支払額を、同じ月の状況を見るための1つの役割として表示する。入力・変更の操作は置かない。

**配置**:

```
┌──────────────────────────────┐
│ グループ名                …  │  ← 002と同じ
│   ‹   2026年9月   ›          │
│      残額 2,175円            │
├──────────┬───────────────────┤
│ けいと   │ 日 月 火 水 木 金 土│
│ 123,456円│          1  2  3  │
│ ████░    │                   │
│ 81%      │   …カレンダー…     │
│──────────│                   │
│ はなこ   │                   │
│ 28,579円 │                   │
│ █░░░░    │                   │
│ 19%      │                   │
└──────────┴───────────────────┘
                          (＋)
```

- 左の列の幅・余白・日付マスの文字の大きさは research.md #1 の表のとおり
- 左の列（`member-spending`）には、`memberTotals` の順に、メンバーごとの項目（`member-spending-item`）を並べる
  - 表示名（`member-spending-name`）: 省略せず折り返す
  - 支払額（`member-spending-amount`）: 「12,345円」の形で省略しない
  - 割合の棒: 幅 = 割合、色 = `colorIndex` の色
  - 割合（`member-spending-percent`）: 「75%」。`percent` が null なら「支出なし」
- 月の移動・3秒ごとの自動更新は002のカレンダーと同じ取得で行う（左の列だけ別に取得しない）
