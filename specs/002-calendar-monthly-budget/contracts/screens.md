# Screen Contract: カレンダー表示と月別予算

各画面の役割（1画面1機能、FR-004）、表示する内容、遷移先の契約。E2Eテストはこの表の遷移を検証する。
URLの決め方は research.md #1 を参照。

## 振り分け（`/`、画面を持たない）

ログイン直後に開かれ、次の順で `redirect()` する（FR-001）。

1. どのグループにも所属していない → `/groups/new`
2. 選択中のグループに予算が一度も設定されていない → `/months/{今月}/budget`
3. それ以外 → `/months/{今月}`

## 画面一覧

| 画面 | URL | 役割 | 開く条件（満たさなければ振り分けへ） |
|---|---|---|---|
| グループ作成 | `/groups/new` | グループ名を入力して作る | ログイン済み |
| グループ切り替え | `/groups` | 所属グループから1つ選ぶ | 1つ以上所属 |
| 予算決定・変更 | `/months/{YYYY-MM}/budget` | その月の設定額を決める | 1つ以上所属 |
| カレンダー | `/months/{YYYY-MM}` | その月の支出を日付ごとに見る | 所属＋予算設定済み（FR-003） |
| 日別詳細 | `/days/{YYYY-MM-DD}` | その日の支出を見る・削除する | 所属＋予算設定済み |
| 支出追加 | `/expenses/new?date=` | 支出を1件入力する | 所属＋予算設定済み |
| 支出編集 | `/expenses/{id}/edit` | 支出を1件直す | 所属＋予算設定済み。支出が選択中グループのもの |
| 招待リンク | `/invite-link` | 招待リンクを発行・コピーする | 1つ以上所属 |

## 各画面の内容と遷移

### グループ作成
- 入力: グループ名
- 作成後 → `/months/{今月}/budget`（新しいグループは予算未設定のため。US4 AC4・AC5）
- 戻る: 所属グループがある場合のみ表示 → カレンダー

### グループ切り替え
- 表示: 所属グループ名の一覧。選択中のものに印を付ける
- 選択後 → `/`（振り分けにより、予算未設定ならそのグループの予算画面、設定済みならカレンダー。FR-027）
- 戻る → カレンダー

### 予算決定・変更
- 表示: 対象の年月、その月の現在の設定額（引き継ぎ後の値を初期値にする）、前月からの繰越額（FR-006）
- 初回（グループに予算が1件もない）: 見出しを「予算を決める」とし、戻るボタンを表示しない
- 保存後 → `/months/{YYYY-MM}`（FR-002）
- 戻る → `/months/{YYYY-MM}`

### カレンダー
- 上部: グループ名（FR-029）、年月（タップ → 予算画面。FR-006）、残額（マイナスは赤字、予算なしの月は
  「予算なし」。FR-013）、3点リーダー（メニュー）
- 前月・翌月ボタン → `/months/{前月|翌月}`（FR-015）
- 本体: 日曜始まり7列のグリッド。各マスに日付と日別合計（支出のない日は金額なし。1万円以上は
  「1.2万」表記。research.md #7）。マスをタップ → `/days/{日付}`（FR-016）
- 「＋」ボタン → `/expenses/new?date={今日}`（FR-018）。表示月が今月でない場合も今日
- 3秒ごとに自動更新（FR-021）

### 日別詳細
- 上部: 日付、その日の合計
- 一覧: 各支出の金額・内容・支払者・支払い方法（FR-019）。支出がなければ「支出はありません」
- 各支出: 編集 → `/expenses/{id}/edit`、削除（確認のうえ即時削除。対象がすでに削除されていれば
  その旨を表示）
- 「＋」ボタン → `/expenses/new?date={その日}`
- 戻る → `/months/{その日の年月}`
- 3秒ごとに自動更新

### 支出追加・支出編集
- 入力: 金額、内容、支払者（グループのメンバーから選ぶ）、支払い方法（現金／モバイル決済）、
  支出日（追加時の初期値は `date` パラメータ、なければ今日）
- 追加・編集は同じ入力フォーム部品を使う。編集は既存の値を初期値にする
- 保存後 → `/days/{保存した支出日}`（支出日を変えた場合も、変更後の日の詳細へ）
- 戻る → 開いた元の画面（ブラウザ履歴）
- 編集の保存時に対象が削除済みなら、その旨を表示する（001のEdge Casesを維持）

### 招待リンク
- 001の InviteSection の機能（発行・コピー）をそのまま移設
- 戻る → カレンダー
