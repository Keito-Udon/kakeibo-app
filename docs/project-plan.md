# kakeibo-app プロジェクトプラン（企画検討メモ）

`/speckit-specify` に入る前に行った、ペルソナ・課題・価値提案・スコープの検討結果をまとめたもの。
本番プロダクトを想定したディスカッションの記録であり、`specs/*/spec.md`（仕様書）の元になった
一次情報として残す。

## ① ペルソナ

- 学生〜20代前半の、半同棲/新婚カップル(男女2人)
- 収入バランス: 男性がやや高収入。女性側は月5万円程度の収入（学生アルバイト等を想定）
- ITリテラシー: スマホアプリでの金銭管理に慣れている

## ② 課題（ペインポイント）

- 共有財布からの支出を女性が単独でスマホアプリに一括入力・管理しており、負担が偏っている
- 既存アプリは2人が同時に閲覧・編集することに対応していない
- モバイル決済に移行したいが、2人分の支出管理が煩雑になるため、あえて現金運用（毎月各自1万円ずつ共有財布に入金）に留まっている

## ③ バリュープロポジション

- 無料で2人が同時に閲覧・編集できること（既存の家計簿アプリは複数人共有が有料プラン限定）
- モバイル決済に移行しても支出記録が破綻しない設計にすることで、現金縛りからの脱却を後押しする
- 自作することによる自由なカスタマイズ性（開発者自身の学習・spec-kit練習という動機も含む）
- 将来的にはレシート画像のOCR読み取りによる入力自動化も視野（本フェーズのスコープ外）

## ④ MVPスコープ

**必須（MVP）**
1. 支出記録の追加（誰が・いくら・何に使ったか）
2. 2人での同時閲覧・編集
3. 月次の可視化（毎月設定額、例: 2万円からの残額逆算方式。使いすぎアラート通知までは求めない）
4. 支払い方法の区別記録（現金／モバイル決済）

**後回し（Phase 2以降）**
- 立て替え精算（誰が誰にいくら返すか）機能
- レシート画像OCR読み取り
- カテゴリ別集計・グラフ
- 定型支出の自動登録

## ⑤ 非機能要件（セキュリティ・プライバシー）

- データはグループ外の第三者に非公開（友人・家族含め、グループメンバー以外には見られたくない）
- ログイン方式: メールアドレス＋パスワードによる一般的な方式で問題ない
- 端末紛失時・利用終了時のデータの扱いについて特別な要望はなし
